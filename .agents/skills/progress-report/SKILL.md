name: progress-report
description: Write a progress report for the current session. Use when the user asks for a progress report or session summary.
---

Write a progress report for this session and save it to `ProgressReports/` at the root of the repo.

The report should summarize the full session:
- The problems or questions the user brought up
- The discussion and decisions made along the way
- Any gotchas or surprises encountered
- The solutions reached

This is a narrative summary, not just a list of code changes. Use a `.md` file named after today's date (e.g., `2026-02-24.md`) or a short descriptive slug if there's a clear topic.
